## 一、版本概述

LLM 路由中转系统首个版本：第三方系统以 OpenAI 兼容协议接入（`model="auto"`），系统经 **L1 规则 → L2 Jev 判定 → L3 组合兜底** 三层路由自动选择下游模型并代为调用；配套 Vue3 管理控制台（10 页面，P0 全量可用）。

> 本版本对应**基线 V1.6**。自 V1.0 起累计变更见 `docs/README.md` §4.1 基线变更记录；
> 各轮端到端验证过程与未闭环项见 `阶段三-开发与实现/03-端到端联调验证记录.md` §七~§十。

## 五、回滚

条件：P0 缺陷、兜底率失守（出现 500 透出）、路由准确率 <70%。方案见部署文档 §六。

## 六、已知限制（不在本版范围——诚实声明）

1. **Jev 官方 API 可达性的事实更正**：K-01 曾预判「Jev 官方 API 对中国大陆不可达」，2026-09-21 实测**该预判不成立**——`https://api.typesafe.ai/v1/systemone` 本机返回 HTTP 200（`model=jev-1.13.0`，延迟 0.4~1.2s），L2 真实判定路径已实测 53/53 通过，`.env` 已切 `JUDGE_PROVIDER=jev`。
   **但**「数据出境合规」问题与可达性无关、依然存在（U-02）；生产是否常开 Jev 需 HD 单独决策，`mock` 仍作为可切换的本地替代实现保留。
2. **内置厂商价格为参考价、非实时报价**：预置的元/百万 token 单价存在时间漂移 / 平台差异 / 计费口径差异三类失真，**上线后须按厂商官网核对**（U-16）。缺失价格留空而非填 0。
3. **内置模型 ID 以 2026-09 为准**：厂商改名 / 下线个别模型 ID 属常态，目录版本号 `CATALOG_VERSION=2026-09` 用于识别；接入后若某模型调用失败，先核对模型名是否仍有效（U-17）。
4. **未内置原生协议厂商**：Anthropic（Claude）/ Google（Gemini）走的是自有协议而非 OpenAI 兼容协议，本期未纳入内置目录，需自建厂商 + 协议适配器（U-18）。
5. **火山方舟等需接入点 ID**：部分厂商的 model_name 并非纯模型名（如需要 `ep-xxxx` 接入点 ID），填错会调用失败，需按该厂商控制台实际值填写（U-19）。
6. L2 语义召回（embedding）未实现（V2 可选优化）。
7. 评测看板为骨架（评测跑批脚本可用，看板图表 V1.1）。
8. 多租户、配额计费、RBAC 细粒度、独立审计表未实现。
9. token 长度为估算值（字符数/2.5），token_len 规则阈值需按语料校准。
10. 用量成本页聚合由前端计算，大数据量下性能待 V1.1 专用聚合接口。
11. **订阅类套餐已纳入路由，合规风险由使用者承担（U-25 —— 重要，请务必阅读）**：
    8 家厂商的 Coding / Token Plan 类套餐已作为独立接入通道预置**并纳入候选池**（V1.6）。
    但厂商官方条款普遍限定这类套餐**只能在厂商官方支持的编程 / 智能体工具中交互式使用，
    不得作为应用后端、自动化脚本或批量任务的主调用通道**，违规可能导致套餐停用或 Key 封禁。
    本系统对外提供 `/v1` 接口，从上游看正属于「应用后端」，**天然落在这条限制内**。
    系统的处置是**不隐瞒**：条款原文落 `provider.terms_note`，控制台可展开警示条，
    给订阅通道首次填 Key 时会**弹窗二次确认**，该通道所有模型标 `单价为参照值`。
    **该产品决策的理由是「通道可用性优先、风险如实告知」，使用前请自行评估合规风险。**
12. **4 条订阅通道暂无可选模型（U-26）**：阿里云百炼 Coding、百度千帆 Token、腾讯混元 Coding、
    月之暗面 Kimi Code——因厂商未公布可折算的 token 单价，系统**刻意不收录模型**
    （凭空填 0 会让其在 L3 成本因子上拿满分、长期霸占路由）。
    如需使用请在「模型池管理」手工添加，**留空也不要填 0**。
13. **Anthropic 协议适配器未实现（U-23）**：各通道 `base_url` 一律取 **OpenAI 兼容**端点；
    厂商另提供的 Anthropic 端点仅为备查记录在 `remark` / `note` 中，当前无法用于调用。
14. 目录中价格为 **2026-09 参考价**，订阅类通道的单价另依赖厂商公布的额度口径，上线前须核对官网（U-16）。
