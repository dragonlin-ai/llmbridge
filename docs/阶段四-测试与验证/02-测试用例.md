## 二、重点用例详情（12 条，执行时照此细化）

### TC-001 关键词规则命中
- **前置**：admin 登录；模型池含 gpt-4o-mini（id=3）
- **数据**：规则 `{"all":[{"field":"text","op":"contains","value":"翻译"}]}` → model 3，priority 10
- **步骤**：规则配置页新增 → 试跑台输入「把下面这句话翻译成英文：你好世界」→ 点试跑
- **预期**：链路条 L1 段绿色高亮；`hit_layer="L1"`；`x-router-confidence` 若走 /v1 则为 1.0；响应头无 task-type；全程 ≤50ms

### TC-011 判定器超时落 L3
- **前置**：`.env` 设 `DECIDER_TIMEOUT_MS=100`，Mock 注入 300ms 延迟
- **预期**：`fallback_reason="DECIDER_UNAVAILABLE"`；HTTP 200（对 /v1 而言）；request_log.router_layer="L3"

### TC-023 上游 429 降级
- **前置**：两条模型 priority 10/20，均 enabled；mock 上游对前者返回 429
- **预期**：最终 200；`x-router-model`=后者；fallback_reason=`UPSTREAM_UNAVAILABLE:<前者model_name>`；成本按后者单价核算

### TC-030 非流式 auto 全链
- **数据**：`{"model":"auto","messages":[{"role":"user","content":"hello"}]}`
- **预期**：body 符合 OpenAI schema（id/object/choices/usage 五要素）；响应头 5 字段齐备且取值合法；L1 时 task-type 头缺失视为通过

### TC-032 SSE 流式首包前决策
- **预期**：`Content-Type: text/event-stream`；每个 data 行可 `json.loads`；`data: [DONE]` 收尾；响应头在**建立连接时**即可读到（证明路由先于首 token）

### TC-043 SSRF 拦截
- **数据**：`http://127.0.0.1:8000`、`http://192.168.1.1`、`http://169.254.169.254` 各试一次
- **预期**：全部 1003，且**不发起任何实际请求**

### TC-058 Redis 宕机可用性
- **步骤**：docker stop redis → 跑 TC-030/046 全套
- **预期**：功能全通；应用日志恰好一条 Redis 降级 WARN；恢复后缓存重新生效

### TC-060 兜底率 100% 专项
- **数据**：20 组异常输入 = 判定超时×4 + 低置信×4 + 上游429×4 + 上游超时×4 + 空候选×4
- **预期**：20/200 3xx；error body 仅含业务错误码；fallback_reason 覆盖 4 类枚举
