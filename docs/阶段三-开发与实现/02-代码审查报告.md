## 二、审查标准

1. 与阶段二设计文档一致（接口契约、字段名、降级矩阵）。
2. 基线边界约定不违反（差异不溢出 adapters/deciders；pipeline 单一）。
3. 安全方案落地（密钥不泄露、SSRF 校验、错误最小化）。
4. 路由模块行覆盖 ≥90%，全局 ≥80%（基线门禁）。
